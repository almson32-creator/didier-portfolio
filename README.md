# Portfolio de Didier

Portfolio one-page présentant le parcours, les apprentissages et les premiers projets de Didier, étudiant en anglais à l'Université d'Abomey-Calavi.

## Technologies

HTML5, CSS3 et JavaScript vanilla. Le site est statique, sans framework ni backend.

## Structure

- `index.html` — contenu et sections de la page.
- `css/style.css` — styles responsive, palette et animations accessibles.
- `js/main.js` — menu mobile, navigation active et année du pied de page.
- `assets/images/` — emplacement des images à ajouter.
- `assets/certificates/` — emplacement des certificats à ajouter.
- `docs/` — documents de travail ignorés par Git.

## Lancement local

Ouvrir `index.html` dans un navigateur. Pour servir le site localement, lancer par exemple `python -m http.server 8000` à la racine puis ouvrir `http://localhost:8000`.

## Sections

Accueil, À propos, Parcours académique, Certifications, Projets, Compétences, Expériences, Langues et Contact.
